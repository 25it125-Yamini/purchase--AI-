# 🛒 PurchaseWise AI

PurchaseWise AI is an AI-powered shopping assistant designed to help users make smarter purchasing decisions. It helps users discover products, compare options, and get personalized recommendations based on their needs, preferences, and budget.

## 🌐 Live Demo

https://purchasewise-ai.vercel.app/

## ✨ Features

- 🤖 AI-powered shopping assistance
- 🔍 Product search and discovery
- ⚖️ Product comparison
- 💡 Personalized product recommendations
- 💰 Budget-based suggestions
- 📊 Easy-to-understand product information
- 📱 Responsive and mobile-friendly interface
- 🎨 Modern and user-friendly design

## 🛠️ Tech Stack

- **Frontend:** Next.js / React
- **Language:** TypeScript / JavaScript
- **Styling:** CSS / Tailwind CSS
- **AI:** AI-powered recommendation system
- **Deployment:** Vercel
- **Version Control:** Git & GitHub
